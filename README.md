## About Me

I'm a backend engineer who builds APIs and services with an eye for how they get attacked — I spent time doing offensive security work before shifting focus to backend development, and that background still shapes how I design auth, validate input, and think about failure modes.

Right now I'm focused on:
- Building backend systems with FastAPI, PostgreSQL, and Redis
- Writing clean, well-tested REST APIs
- Understanding systems deeply enough to break them, then building them so they don't break
