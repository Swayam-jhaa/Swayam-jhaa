## ⚡ About Me

I am a **Backend Systems Engineer** and **Security Researcher** specializing in resilient API design, asynchronous processing pipelines, and AI-driven analytical platforms. With an offensive security background, I engineer backend systems with an "Assume Breach" and "Fail-Closed" mindset — treating authentication, input sanitization, rate-limiting, and state divergence as first-class architectural concerns.

- 🛠️ **Systems & Frameworks**: FastAPI, Next.js (App Router), Node.js, Express, Docker, Redis, Celery.
- 🗄️ **Databases & ORMs**: PostgreSQL, MySQL, MongoDB, SQLite, Prisma ORM, SQLAlchemy.
- 🛡️ **Security Research**: Attack Surface Management (ASM), Automated Reconnaissance, OWASP Top 10, Burp Suite, Nmap.
- 🧠 **Analytical & AI**: Burn-In Stress Anomaly Detection (SIH 2026), Multi-Agent Reporting Systems, OSINT Aggregation.

## 🚀 Featured Flagship Projects

### 🌟 [Predicta — AI-Driven Anomaly Detection & Screening Pipeline](https://github.com/Swayam-jhaa/Predicta)
*Smart India Hackathon 2026 (Problem Statement 170)*  
High-reliability component burn-in and screening system designed for aerospace and defense electronics.
- **Analytical Core**: Modular engine combining **Module A** (MAD outlier filter) and **Module B** (linear drift trajectory predictor) with explainable root-cause heuristics.
- **Full-Stack Pipeline**: FastAPI backend serving parametric health predictions and interactive Next.js cockpit with live trajectory projection and what-if simulation.
- 🌐 [Live Deployment](https://predicta-bay.vercel.app) | 📦 [Repository](https://github.com/Swayam-jhaa/Predicta)

### 🛡️ [SENTINEL-SCAN — Attack Surface Management Platform](https://github.com/Swayam-jhaa/SENTINEL-SCAN)
Production-grade, asynchronous reconnaissance and attack surface monitoring engine.
- **Producer-Consumer Architecture**: High-speed subdomain enumeration and live service probing using `asyncio.Queue`.
- **Targeted Probing**: Detects misconfigurations, exposed secrets, and security regressions with real-time alerting.
- 📦 [Repository](https://github.com/Swayam-jhaa/SENTINEL-SCAN)

### 🤖 [Agentic Pentest Reporting Engine (APRE)](https://github.com/Swayam-jhaa/Agentic-Pentest-Reporting-Engine)
Autonomous multi-agent framework that parses raw scanner outputs (Nmap, Burp, ZAP) and synthesizes enterprise-grade penetration testing reports conforming to OWASP and NIST standards.
- 🌐 [Live Deployment](https://agentic-pentest-reporting-engine.vercel.app) | 📦 [Repository](https://github.com/Swayam-jhaa/Agentic-Pentest-Reporting-Engine)

### 🧵 [StitchIT — Bespoke Apparel & Tailoring Platform](https://github.com/Swayam-jhaa/StitchIT)
Full-stack web application featuring role-based access control (RBAC), multi-step custom ordering workflows, and administrative management.
- **Tech Stack**: Next.js 15, TypeScript, Prisma ORM, PostgreSQL, Clerk Authentication, Tailwind CSS.
- 📦 [Repository](https://github.com/Swayam-jhaa/StitchIT)

### 🔍 [DeCognito — OSINT Aggregation Engine](https://github.com/Swayam-jhaa/DeCognito)
Modular multi-source digital footprint reconnaissance framework combining Sherlock username enumeration, Shodan infrastructure profiling, and Celery asynchronous queues.
